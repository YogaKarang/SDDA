Tugas kelompok

Merancang hash function sederhana untuk memetakan nama-nama ke dalam array dengan ukuran 10, lalu gunakan pendekatan sederhana seperti menjumlahkan seluruh karakter ASCII dari nama, kemudian menghitung hash index, lalu distribusikan nama-nama ke dalam array dan buat program (syntax) untuk metode optimal, disini kami menggunakan metode Linked List Chaining.

Program ini dirancang untuk mengubah data berupa nama menjadi index menggunakan hash function (jumlah ASCII), kemudian menyimpannya ke dalam array berukuran tertentu. Jika terjadi collision, program menggunakan metode Linked List Chaining untuk menyimpan lebih dari satu data dalam satu index, sehingga seluruh data tetap dapat dimasukkan tanpa kehilangan.
